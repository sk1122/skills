# Decisions

The important decisions behind this code, approved by a person. Coding agents read this file before working, follow what it says, and ask before making a new decision of this size.

"Important" means it would hurt the app later if it were wrong: storage that won't scale, data loss, security and access, new dependencies or services, contracts, cost, product rules, or anything hard to undo. Everyday code choices aren't recorded here.

Each entry says when it stops holding ("Revisit when"). When the work crosses that line, the agent raises the decision again.
